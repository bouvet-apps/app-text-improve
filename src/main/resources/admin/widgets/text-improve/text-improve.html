Text improve

- automated microtest of text content -

A text always has a message you want to convey. But does the message align with a reader's expectation of the text? A microtest of the text can improve and make the text more user-oriented. Users often have questions that you haven't thought of yourself.

Laura Arlov (Skatteetaten) has developed a method for running a quick microtest of textual content. The method involves letting a number of test users read the title and preface of a text. The test users then write down questions they expect to be answered in the rest of the text.
The test users then read the rest of the text and note whether their questions were answered.

Then you look at the following:

  • Are the questions well enough answered?
  • Is there unnecessary information?

The results from such a microtest can be used to improve the content of the text, so that it aligns more with the readers' expectations.

This widget is based on the method outlined above, but automates the process by using AI (ChatGPT) instead of actual test persons. This way, editors can quickly and easily quality-check their texts, directly in Content Studio!
